## What I do

I design and ship software at the intersection of **large language models, product engineering and business operations** — from the first architecture diagram to the deployed system.

| | Focus |
|---|---|
| **01** | **LLM products** — model integrations, structured outputs, tool use and reliable workflows |
| **02** | **AI systems** — agents, retrieval, orchestration, evaluation and human-in-the-loop flows |
| **03** | **SaaS engineering** — full-stack products, APIs, data pipelines and operational interfaces |
| **04** | **Delivery** — turning ambiguous problems into software that people can actually use |
